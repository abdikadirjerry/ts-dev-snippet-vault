# Developer Code Snippet Vault (`ts-dev-snippet-vault`)

A clean developer code snippet repository and manager featuring language filters, instant search, one-click code copying, and an editorial IDE dark aesthetic built with React, TypeScript, and Tailwind CSS.

## Features

- **Language Filtering:** Quick toggles for TypeScript, Python, SQL, React, and Docker snippets.
- **One-Click Copy:** Instant clipboard copying for any code block.
- **Snippet Creation Modal:** Add custom snippets with tags, descriptions, and syntax blocks.
- **Strict TypeScript Types:** Fully typed interface contracts across all repository components.

## Setup & Running

1. Clone repository & install dependencies:
   ```bash
   cd ts-dev-snippet-vault
   npm install
   ```
